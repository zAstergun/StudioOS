# Receita viral

O objetivo é aplicar a estrutura de um formato de sucesso ao tema fornecido pelo usuário, sem fazer perguntas adicionais. Use o que foi fornecido na entrada (nicho, público, ideia).

## O que a receita captura

- O formato: texto, imagem, carrossel, video.
- O hook: as primeiras linhas visíveis antes do ver mais.
- A legenda: como é construída, ritmo, o que cada seção faz.
- A entrega: quebra de linha, cadência, tom.

## Como agir

Use as informações fornecidas para criar o conteúdo imediatamente:
1. Analise o contexto e deduza o "insumo" ideal (história, número, exemplo) para o público alvo.
2. Escreva o hook usando o mesmo formato e shape das melhores receitas virais daquele nicho.
3. Escreva a legenda seguindo a estrutura de retenção forte e ritmo variado.
4. Entregue o texto/roteiro pronto para uso.

## Guardrail honesto

Receita viral funciona porque um dia pareceu fresca. Espelhe a estrutura que prende a atenção, mas adapte criativamente para não parecer robótico ou formulaico demais. Evite linguagem clichê de IA.
